## Ход выполнения работы

### 1. Write Model

**Агрегат:** Response (Ответ респондента)

**Структура:**
- Нормализованная таблица `responses` с полями: response_id (PK), form_id, answers (JSON), started_at, submitted_at, ip_address, user_agent, geo_country, geo_city, device_type, filling_time_sec, quality_score, is_suspect, suspect_reason
- Отдельные таблицы для форм (`forms`) и агрегатов (`form_aggregates`)
- Инварианты: ответ не может быть классифицирован дважды; quality_score в диапазоне 0-1; для отписки обязательна причина

---

### 2. Read Model

**Проекция:** ResponseView (денормализованное представление ответа)

**Структура:**
- Денормализованная таблица `response_views` с полями: response_id (PK), form_id, form_title (денормализовано из forms), answers, rating, comment, started_at, submitted_at, filling_time_sec, ip_address, country, city, device_type, is_suspect, quality_score
- JOIN предзагружены (form_title подтягивается при создании проекции)
- Индексы: form_id, (form_id, submitted_at), (form_id, rating), (form_id, is_suspect)

**Скриншот БД:**

```sql
-- EXPLAIN запроса для статистики по форме
EXPLAIN ANALYZE
SELECT form_id, COUNT(*) as total, AVG(quality_score) as avg_quality
FROM response_views
WHERE form_id = 'FORM-42'
GROUP BY form_id;

```

### 3. Event-Driven Sync

**События:**
- `ResponseClassifiedEvent` → обновить ResponseView (is_suspect, quality_score)
- `ResponseEnrichedEvent` → обновить ResponseView (country, city, device_type)

**Код:**

```python
# cqrs/projection/response_projection.py
import logging
from domain.events.response_events import ResponseClassifiedEvent, ResponseEnrichedEvent
from cqrs.read_model.response_view_repository import ResponseViewRepository

logger = logging.getLogger(__name__)

class ResponseProjection:
    def __init__(self, view_repository: ResponseViewRepository):
        self.view_repository = view_repository
    
    def on_response_classified(self, event: ResponseClassifiedEvent) -> None:
        existing = self.view_repository.find_by_id(event.response_id)
        if existing:
            existing.is_suspect = event.is_suspect
            existing.quality_score = event.quality_score
            existing.updated_at = event.occurred_at
            self.view_repository.save(existing)
            logger.info(f"Projection updated for {event.response_id}")
    
    def on_response_enriched(self, event: ResponseEnrichedEvent) -> None:
        existing = self.view_repository.find_by_id(event.response_id)
        if existing:
            existing.country = event.geo_country
            existing.city = event.geo_city
            existing.device_type = event.device_type
            existing.updated_at = event.occurred_at
            self.view_repository.save(existing)
            logger.info(f"Projection enriched for {event.response_id}")
```
