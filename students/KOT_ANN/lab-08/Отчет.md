## Ход выполнения работы

### 1. Response Processor Service

**Bounded Context:** Обработка ответов (обогащение гео-данными, антиспам-классификация, сохранение)

**API:**
- POST `/api/responses` - обработка ответа
- GET `/api/responses/{id}` - получение ответа по ID
- GET `/api/responses/aggregates/{form_id}` - получение статистики формы
- GET `/api/responses` - список ответов формы (пагинация)

---

### 2. Group Service

**Bounded Context:** Управление формами (CRUD, схемы полей, настройки антиспама)

**API:**
- POST `/api/forms` - создание формы
- GET `/api/forms/{id}` - получение схемы формы

---

### 3. Event Bus (RabbitMQ)

**События:**
- `ResponseClassified` - ответ классифицирован (качественный/отписка)
- `ResponseEnriched` - ответ обогащён гео-данными

**Схема обмена:**

| Exchange | Type | Queue | Routing Key |
|----------|------|-------|-------------|
| `response.events` | topic | `notification.queue` | `response.classified` |

---

### 4. API Gateway

**Маршрутизация:**
- `/api/responses/**` → Response Processor Service (порт 8000)
- `/api/forms/**` → Form Service (порт 8001)
- `/api/notifications/**` → Notification Service (порт 8002)

**Конфигурация nginx.conf:**

```nginx
upstream response_service {
    server response-processor:8000;
}

upstream form_service {
    server form-service:8001;
}

upstream notification_service {
    server notification-service:8002;
}

server {
    listen 80;
    
    location /api/responses {
        proxy_pass http://response_service;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    location /api/forms {
        proxy_pass http://form_service;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    location /api/notifications {
        proxy_pass http://notification_service;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    location /health {
        return 200 'OK';
        add_header Content-Type text/plain;
    }
}
```
