### 1. Value Objects (Ценностные Объекты)

**Созданные Value Objects:**

1. **FormField** - описывает поле формы: имя, тип, обязательность, ограничения
   - Валидация: тип поля должен быть из списка (text, integer, rating, email, phone, date, checkbox); имя поля не может быть пустым
   - Иммутабельность: ✅ (использует dataclass(frozen=True))
   - Файл: `domain/models/form.py`

2. **AntiSpamSettings** - настройки детекции отписок: минимальное время заполнения, минимальная длина комментария, блокировка повторящихся символов
   - Валидация: min_filling_time_sec >= 0, min_comment_length >= 0
   - Иммутабельность: ✅ (использует dataclass(frozen=True))
   - Файл: `domain/models/form.py`

3. **FormAggregates** - агрегированная статистика формы: total_responses, quality_responses, suspect_responses, average_rating
   - Валидация: рейтинг при добавлении должен быть 1-5; нельзя добавить рейтинг без ответов
   - Иммутабельность: ❌ (агрегаты изменяются через методы increment_*)
   - Файл: `domain/models/aggregate.py`

4. **ResponseClassifiedEvent** - событие классификации ответа (качественный/отписка)
   - Валидация: отсутствует (чистый DTO)
   - Иммутабельность: ✅ (dataclass)
   - Файл: `domain/events/response_events.py`

5. **ResponseEnrichedEvent** - событие обогащения ответа (гео, устройство)
   - Валидация: отсутствует (чистый DTO)
   - Иммутабельность: ✅ (dataclass)
   - Файл: `domain/events/response_events.py`

**Пример кода** (FormField):

from dataclasses import dataclass, field
from domain.exceptions.domain_exception import DomainException


@dataclass(frozen=True)
class FormField:
    """Value Object: Поле формы"""
    
    name: str
    field_type: str
    required: bool = False
    constraints: dict = field(default_factory=dict)
    
    VALID_TYPES = {"text", "integer", "rating", "email", "phone", "date", "checkbox"}
    
    def __post_init__(self):
        if self.field_type not in self.VALID_TYPES:
            raise DomainException(
                f"Invalid field type: {self.field_type}",
                code="INVALID_FIELD_TYPE"
            )
        if not self.name or not self.name.strip():
            raise DomainException(
                "Field name cannot be empty",
                code="EMPTY_FIELD_NAME"
            )

### 2. Entities (Сущности)

**Созданные Entity:**

1. **Response** - ответ респондента на форму. Содержит данные ответа, метаданные (IP, User-Agent), результаты обогащения (гео, устройство, время заполнения) и классификации (quality_score, is_suspect)
   - ID поле: `response_id`
   - Бизнес-правила: время заполнения не может быть отрицательным; нельзя классифицировать ответ дважды; quality_score должен быть в диапазоне 0-1; при классификации отписки обязательно указание причины; проверка is_quality_response() и is_suspect_response() доступны только после классификации
   - Файл: `domain/models/response.py`

2. **Form** - форма с вопросами и настройками антиспама. Хранит схему полей (имя, тип, обязательность) и настройки детекции отписок
   - ID поле: `form_id`
   - Бизнес-правила: форма должна содержать хотя бы одно поле; имена полей должны быть уникальны; тип поля должен быть валидным; имя поля не может быть пустым; при добавлении поля с существующим именем — исключение
   - Файл: `domain/models/form.py`

**Пример кода** (Response):

```python
from dataclasses import dataclass, field
from datetime import datetime
from typing import Dict, Any, Optional
from domain.exceptions.domain_exception import DomainException


@dataclass
class Response:
    response_id: str
    form_id: str
    answers: Dict[str, Any]
    started_at: datetime
    submitted_at: datetime
    ip_address: Optional[str] = None
    user_agent: Optional[str] = None
    
    geo_country: Optional[str] = None
    geo_city: Optional[str] = None
    device_type: Optional[str] = None
    device_os: Optional[str] = None
    device_browser: Optional[str] = None
    filling_time_sec: Optional[int] = None
    quality_score: Optional[float] = None
    is_suspect: Optional[bool] = None
    suspect_reason: Optional[str] = None
    
    _is_classified: bool = field(default=False, init=False, repr=False)
    
    def calculate_filling_time(self) -> int:
        delta = self.submitted_at - self.started_at
        seconds = int(delta.total_seconds())
        if seconds < 0:
            raise DomainException(
                f"Filling time cannot be negative: {seconds}",
                code="NEGATIVE_FILLING_TIME"
            )
        self.filling_time_sec = seconds
        return seconds
    
    def classify(self, quality_score: float, is_suspect: bool, suspect_reason: Optional[str] = None) -> None:
        if self._is_classified:
            raise DomainException(
                f"Response {self.response_id} already classified",
                code="ALREADY_CLASSIFIED"
            )
        if not 0 <= quality_score <= 1:
            raise DomainException(
                f"Quality score must be between 0 and 1, got {quality_score}",
                code="INVALID_QUALITY_SCORE"
            )
        if is_suspect and not suspect_reason:
            raise DomainException(
                "Suspect reason is required when is_suspect=True",
                code="MISSING_SUSPECT_REASON"
            )
        
        self.quality_score = quality_score
        self.is_suspect = is_suspect
        self.suspect_reason = suspect_reason
        self._is_classified = True
    
    def is_quality_response(self) -> bool:
        if not self._is_classified:
            raise DomainException(
                f"Response {self.response_id} not classified yet",
                code="NOT_CLASSIFIED"
            )
        return self.is_suspect is False
```

### 3. Aggregate Root (Корневой агрегат)

**Aggregate Root:** Form (Форма)

**Границы агрегата:**
- Корень: `Form`
- Внутренние сущности: нет (Form не содержит других сущностей, только Value Objects)
- Value Objects: `FormField`, `AntiSpamSettings`

**Инварианты агрегата:**

| № | Инвариант | Как проверяется |
|---|----------|----------------|
| 1 | Форма должна содержать хотя бы одно поле | В `__post_init__()` после создания Form |
| 2 | Имена полей должны быть уникальными | В `__post_init__()` при создании Form |
| 3 | Нельзя добавить поле с уже существующим именем | В методе `add_field()` |
| 4 | Тип поля должен быть валидным (text, integer, rating, email, phone, date, checkbox) | В `__post_init__()` FormField |
| 5 | Имя поля не может быть пустым | В `__post_init__()` FormField |
| 6 | min_filling_time_sec не может быть отрицательным | В `__post_init__()` AntiSpamSettings |
| 7 | min_comment_length не может быть отрицательным | В `__post_init__()` AntiSpamSettings |

**Пример кода Aggregate Root:**

```python
from dataclasses import dataclass, field
from typing import List, Dict, Any, Optional
from domain.exceptions.domain_exception import DomainException


@dataclass(frozen=True)
class FormField:
    name: str
    field_type: str
    required: bool = False
    constraints: Dict[str, Any] = field(default_factory=dict)
    
    VALID_TYPES = {"text", "integer", "rating", "email", "phone", "date", "checkbox"}
    
    def __post_init__(self):
        if self.field_type not in self.VALID_TYPES:
            raise DomainException(
                f"Invalid field type: {self.field_type}",
                code="INVALID_FIELD_TYPE"
            )
        if not self.name or not self.name.strip():
            raise DomainException(
                "Field name cannot be empty",
                code="EMPTY_FIELD_NAME"
            )


@dataclass(frozen=True)
class AntiSpamSettings:
    min_filling_time_sec: int = 30
    min_comment_length: int = 3
    block_repeating_chars: bool = True
    
    def __post_init__(self):
        if self.min_filling_time_sec < 0:
            raise DomainException(
                f"min_filling_time_sec cannot be negative: {self.min_filling_time_sec}",
                code="INVALID_ANTISPAM_SETTING"
            )
        if self.min_comment_length < 0:
            raise DomainException(
                f"min_comment_length cannot be negative: {self.min_comment_length}",
                code="INVALID_ANTISPAM_SETTING"
            )


@dataclass
class Form:
    form_id: str
    fields: List[FormField]
    anti_spam_settings: AntiSpamSettings = field(default_factory=AntiSpamSettings)
    
    def __post_init__(self):
        if not self.fields:
            raise DomainException(
                "Form must have at least one field",
                code="EMPTY_FORM"
            )
        
        field_names = [f.name for f in self.fields]
        duplicates = [name for name in field_names if field_names.count(name) > 1]
        if duplicates:
            raise DomainException(
                f"Duplicate field names: {set(duplicates)}",
                code="DUPLICATE_FIELD_NAMES"
            )
        
        self._fields_dict = {f.name: f for f in self.fields}
    
    def get_field(self, name: str) -> Optional[FormField]:
        return self._fields_dict.get(name)
    
    def is_field_required(self, field_name: str) -> bool:
        field = self.get_field(field_name)
        return field.required if field else False
    
    def get_required_fields(self) -> List[str]:
        return [name for name, field in self._fields_dict.items() if field.required]
    
    def add_field(self, field: FormField) -> None:
        if field.name in self._fields_dict:
            raise DomainException(
                f"Field with name '{field.name}' already exists",
                code="DUPLICATE_FIELD"
            )
        self._fields_dict[field.name] = field
        self.fields = list(self._fields_dict.values())
    
    def validate_answers(self, answers: Dict[str, Any]) -> None:
        for required_field in self.get_required_fields():
            if required_field not in answers or answers[required_field] is None:
                raise DomainException(
                    f"Missing required field: {required_field}",
                    code="MISSING_REQUIRED_FIELD"
                )
```

## Контрольные вопросы

1. **В чём отличие Value Object от Entity?**
   - Value Object определяется своими атрибутами, не имеет идентификатора и является иммутабельным. Два Value Object с одинаковыми атрибутами считаются равными. Entity имеет уникальный идентификатор (ID) и может менять свои атрибуты с течением времени, оставаясь той же сущностью. В моей системе FormField и AntiSpamSettings — Value Objects, Response и Form — Entities.

2. **Почему Aggregate Root должен инкапсулировать доступ к внутренним сущностям?**
   - Aggregate Root обеспечивает согласованность данных внутри агрегата. Внешний код не может напрямую изменить внутреннюю сущность, минуя бизнес-правила. В моей системе Form является Aggregate Root, управляет FormField и проверяет инварианты (уникальность имён полей, наличие хотя бы одного поля) при любом изменении.

3. **Какая роль Domain Events? Приведите пример из вашей системы.**
   - Domain Events уведомляют другие части системы о важных изменениях в домене. Они позволяют отделить побочные эффекты (уведомления, обновление отчётов) от основной бизнес-логики. В моей системе ResponseClassifiedEvent генерируется при классификации ответа и может использоваться для отправки уведомления автору формы или обновления аналитики.

4. **Как вы проверяете инварианты в вашем агрегате? Приведите пример.**
   - Инварианты проверяются в методах агрегата и в конструкторе. Например, в методе `classify()` проверяется: ответ не может быть классифицирован дважды, quality_score должен быть в диапазоне 0-1, для отписки обязательно указание причины. Если инвариант нарушен — выбрасывается DomainException с соответствующим кодом ошибки.

5. **Почему Value Objects делаются иммутабельными?**
   - Иммутабельность Value Objects гарантирует, что их состояние не изменится после создания. Это позволяет безопасно использовать их в нескольких местах, не опасаясь побочных эффектов. Если нужно изменить значение — создаётся новый объект. В моей системе FormField и AntiSpamSettings используют `@dataclass(frozen=True)` для обеспечения иммутабельности.
